# ABUSE_PREVENTION.md — 어뷰징·봇 트래픽·사칭·도메인 및 과금 남용 방지 대책

## 1. 엔드포인트별 정밀 Rate Limiting 정책
| 대상 작업 | 제한 기준 (Redis Sliding Window) | 초과 시 동작 |
| :--- | :--- | :--- |
| 로그인 시도 (`POST /api/v1/auth/login`) | IP당 5분 10회 / 계정당 5회 실패 | `429` 후 10회 연속 실패 시 15분 계정 잠금(`423`) + 본인 확인 이메일 발송 |
| 회원가입 (`POST /api/v1/auth/register`) | IP당 시간당 10회 | `429 Too Many Requests` + Turnstile Captcha 강제 |
| 게시글 발행 (`POST .../publish`) | 사용자당 분당 5회 / 시간당 30회 | `429` 반환 |
| 댓글/방명록 작성 | 사용자당 분당 5회, 동일 본문 연속 등록 차단 | `429` 또는 중복 댓글 거부 |
| 미디어 업로드 세션 발급 | 사용자당 분당 30회 / 일일 총 용량 2GB | `429` 또는 `413 Quota Exceeded` |
| 커스텀 도메인 DNS 검증 요청 | 블로그당 시간당 20회 | 무분별한 외부 DNS 쿼리 증폭 공격 방지 |

## 2. 유명인/공식 브랜드 사칭(Impersonation) 및 피싱 방어
- 공식 인증 배지(`verified_badge`)는 관리자가 실제 법인/도메인 소유권을 확인한 블로그에만 부여하며, 사용자가 닉네임에 특수기호(`✔`, `☑️`)를 넣어 인증 배지를 위장하는 행위를 필터링한다.
