# CONTENT_MODERATION.md — 신고·검토·조치·이의신청 운영 워크플로 명세 (제16조)

## 1. 엔드투엔드 모더레이션 상태 머신
```
[신고 접수 (POST /api/v1/reports) 또는 자동 스팸 고위험 감지]
                              │
                              ▼
             [moderation_cases 생성 / 병합 (status = OPEN)]
              - 다수 신고 누적 또는 권리침해(DMCA/명예훼손) 시 우선순위 상향
                              │
                              ▼
          [모더레이터 배정 및 심사 (status = IN_REVIEW)]
           - 원문 스냅샷(snapshot_json), 신고 사유, 증빙 자료 검토
                              │
         ┌────────────────────┴────────────────────┐
         ▼ (위반 없음)                             ▼ (정책 위반 또는 법적 임시조치 필요)
[기각 (status = DISMISSED)]              [제재 조치 실행 (status = ACTION_TAKEN)]
 - 신고자에게 결과 통지                   - 게시글 `QUARANTINED` (451 응답, 색인 즉시 제거)
                                          - 작성자에게 구체적 위반 조항 및 이의신청 링크 발송
                                                   │
                                                   ▼ (작성자 소명 제출: POST /api/v1/me/appeals)
                                         [이의신청 접수 (status = APPEALED)]
                                          - 최초 처분자와 다른 시니어 모더레이터가 재심사
                                                   │
                                  ┌────────────────┴────────────────┐
                                  ▼ (소명 타당/오탐 확인)           ▼ (위반 명백)
                        [복원 승인 (APPROVED_RESTORED)]   [기각 확정 (REJECTED_UPHELD)]
                         - 게시글 `PUBLISHED` 원상복구     - 게시중단/삭제 유지 및 최종 통지
                         - 검색 색인 즉시 재등록
```

## 2. 인적 검토(Human-in-the-Loop) 보장 원칙 (제16조 준수)
자동 스팸 필터나 AI 분류기는 모더레이션 우선순위를 높이는 보조 수단으로만 사용하며, 만약 고위험 스팸/피싱으로 자동 임시 격리(`AUTO_QUARANTINED`)된 경우에도 작성자가 원클릭으로 이의신청을 제출하면 반드시 24~48시간 내에 인적 검토(Human Review)를 거쳐 복구될 수 있는 절차를 보장한다.
