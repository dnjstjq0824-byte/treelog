# ANTI_SPAM.md — 스팸 게시글·악성 댓글·봇 가입 다단계 탐지 및 차단 명세

## 1. 계정 신뢰도 등급 (`users.trust_tier`: 0 ~ 5) 기반 점진적 제한
신규 자동 가입 봇이 대량의 스팸 블로그와 게시글을 살포하는 것을 막기 위해 계정 신뢰도 등급별 일일 쿼터를 차등 적용한다.
- **Tier 0 (이메일 미인증)**: 블로그 개설 및 댓글 작성 불가.
- **Tier 1 (신규 가입 후 24시간 이내)**: 블로그 개설 최대 1개, 일일 공개 게시글 발행 최대 5건, 본문 내 외부 링크 3개 초과 시 적응형 Captcha(Turnstile) 요구, 댓글 작성 분당 3건 제한.
- **Tier 2 (정상 활동 7일 이상 & 신고 누적 없음)**: 일일 게시글 30건, 외부 링크 제한 완화.
- **Tier 3~5 (인증된 크리에이터 / 기업 블로그)**: 대량 시리즈 발행 및 이전(Import) 허용.

## 2. 실시간 스팸 시그널 스코어링 (`spam_detection_results`)
1. **텍스트/링크 휴리스틱**: 불법 도박/성인/불법대출 금칙어 정규식 패턴, 단축 URL(bit.ly 등) 다중 중첩, 보이지 않는 유니코드 제로폭 문자(Zero-width characters) 삽입 탐지.
2. **행동 패턴 분석**: 가입 후 10초 이내 첫 글 발행, 클립보드 대량 붙여넣기 후 1초 만에 발행, 1분 내 10개 이상의 서로 다른 블로그에 동일 문구 댓글 살포 시 즉시 `AUTO_QUARANTINED` 처리.
