# RESPONSIVE_ACCESSIBILITY.md — 320px~데스크톱 반응형 레이아웃 및 웹 접근성(a11y) 표준

## 1. 뷰포트 브레이크포인트별 레이아웃 정책 (제4조)

| 구간 코드 | 해상도 범위 | 그리드 컬럼 | 네비게이션 및 사이드바 동작 | 에디터 및 테이블 대응 |
| :--- | :--- | :--- | :--- | :--- |
| **`xs` (초소형/일반 모바일)** | `320px ~ 639px` | 4 Columns (`16px` margin) | 상단 컴팩트 헤더 + 하단 탭바(탐색/피드/글쓰기/알림/내블로그), 블로그 사이드바는 슬라이드 드로어로 전환 | 소프트 키보드 상단 고정 툴바, 표(Table)는 가로 스크롤 컨테이너 자동 래핑 |
| **`sm` (대형 모바일)** | `640px ~ 767px` | 6 Columns (`20px` margin) | 1열 와이드 카드, 하단 고정 공감/댓글 액션바 | 모바일 터치 이미지 리사이즈 프리셋 |
| **`md` (태블릿)** | `768px ~ 1023px` | 8 Columns (`24px` margin) | 탐색 그리드 2열 배치, 블로그 상세는 본문 집중 1열 + 접이식 드로어 | 태블릿 플로팅 툴바 + 우측 오버레이 설정창 |
| **`lg` (표준 데스크톱)** | `1024px ~ 1279px` | 12 Columns (`32px` margin) | 좌측/우측 사이드바(`280px`) + 중앙 본문(`720px`) 2단 레이아웃 | 본문 캔버스 + 우측 고정 설정 패널 |
| **`xl / 2xl` (대형 모니터)** | `1280px ~ 2560px+` | 12 Columns (Max container `1440px`) | 좌측 카테고리/프로필(`260px`) + 중앙 본문(`740px`) + 우측 실시간 목차 TOC(`240px`) 3단 균형 배치 | 와이드 블록 및 듀얼 프리뷰 모드 지원 |

## 2. WCAG 2.1 AA 접근성 필수 체크리스트
1. **키보드 완전 조작성**: 마우스 없이 `Tab`, `Shift+Tab`, `Enter`, `Space`, `Escape`, 방향키만으로 모든 메뉴, 에디터 툴바, 공감 버튼, 모달을 100% 조작할 수 있어야 한다.
2. **포커스 트랩 및 복귀**: 신고 모달, 이미지 라이트박스, 테마 설정 모달이 열리면 포커스가 모달 내부로 제한되고 닫힐 때 원래 트리거 버튼으로 정확히 복귀한다.
3. **스크린리더 대체 텍스트 강제**: 이미지 업로드 시 `alt` 입력란을 기본 노출하며, 아이콘 단독 버튼(검색, 북마크, 알림, 다크모드)은 모두 `aria-label`을 필수로 가진다.
4. **`prefers-reduced-motion` 존중**: 시스템에서 애니메이션 축소를 설정한 사용자에게는 스켈레톤 깜빡임과 페이지 전환 트랜지션을 즉시 비활성화한다.
