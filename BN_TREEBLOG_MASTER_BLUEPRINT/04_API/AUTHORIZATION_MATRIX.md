# AUTHORIZATION_MATRIX.md — 2계층 RBAC 및 게시글 가시성 권한 매트릭스

## 1. 개별 블로그 팀 역할 매트릭스 (Blog-Level RBAC)

| 기능 / API 액션 | `ANON` (비로그인) | `USER` (일반 독자) | `ANALYST` (통계열람) | `AUTHOR` (필진) | `EDITOR` (편집자) | `ADMIN` (블로그관리자) | `OWNER` (블로그소유자) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 공개 게시글 열람 (`PUBLIC`) | O | O | O | O | O | O | O |
| 공감 / 댓글 / 방명록 작성 (허용 시) | X | O | O | O | O | O | O |
| 블로그 방문자·유입 통계 상세 조회 | X | X | **O** | 본인 글만 | O | O | O |
| 본인 게시글 작성 / 자동저장 / 수정 | X | X | X | **O** | O | O | O |
| 본인 게시글 즉시 발행 | X | X | X | 설정에 따름* | **O** | O | O |
| 타 멤버의 초안 검토 / 수정 / 발행 승인 | X | X | X | X | **O** | O | O |
| 공지사항 고정 / 카테고리·시리즈 편집 | X | X | X | X | **O** | O | O |
| 블로그 기본 설정 / 테마 / 커스텀 도메인 변경 | X | X | X | X | X | **O** | O |
| 팀 블로그 멤버 초대 및 역할 변경 | X | X | X | X | X | **O** (Owner 제외) | O |
| 광고 슬롯 설정 / 수익 원장 조회 / 정산 출금 | X | X | X | X | X | X | **O (MFA)** |
| 블로그 소유권 이전 / 블로그 폐쇄 신청 | X | X | X | X | X | X | **O (MFA)** |

> `*` 기업 블로그에서 `blog_settings.require_approval_for_authors = true`인 경우, `AUTHOR`는 초안 작성 및 '검토 요청(`IN_REVIEW`)'까지만 가능하며 실제 발행은 `EDITOR` 이상이 승인해야 한다.

## 2. 게시글 공개 범위(`visibility`)별 열람 권한 매트릭스

| 게시글 `visibility` 설정값 | 비로그인 (`ANON`) | 일반 로그인 (`USER`) | 팔로워 (`FOLLOW`) | 단방향 이웃 (`NEIGHBOR`) | 양방향 상호이웃 (`MUTUAL_NEIGHBOR`) | 유료 멤버십/구매자 (`PAID`) | 작성자 및 블로그 `EDITOR+` | OpenSearch / Sitemap / TreeScan 노출 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **`PUBLIC` (전체 공개)** | O | O | O | O | O | O | O | **O (색인 허용)** |
| **`UNLISTED` (링크 공개)** | O (링크 직접 접근 시) | O | O | O | O | O | O | **X (`noindex`, 색인 제외)** |
| **`NEIGHBOR_ONLY` (이웃 공개)** | X (`403`) | X (`403`) | X (`403`) | **O** | **O** | X | O | **X (절대 제외)** |
| **`MUTUAL_ONLY` (상호이웃 공개)** | X (`403`) | X (`403`) | X (`403`) | X (`403`) | **O (`ACCEPTED`)** | X | O | **X (절대 제외)** |
| **`PAID_MEMBERS_ONLY` (유료 전용)** | 티저만 | 티저만 | 티저만 | 티저만 | 티저만 | **O (전문 열람)** | O | **티저만 메타 색인 (본문 제외)** |
| **`PRIVATE` (비공개)** | X (`403/404`) | X (`403/404`) | X (`403/404`) | X (`403/404`) | X (`403/404`) | X (`403/404`) | **O** | **X (절대 제외)** |
