# REVISION_SYSTEM.md — 게시글 수정 이력(Revision) 및 Diff 복원 시스템

## 1. 리비전 생성 시점 및 보관 정책
1. **생성 조건**:
   - 최초 발행(`PUBLISHED`) 시 `revision_no = 1` 스냅샷 생성.
   - 발행된 게시글을 수정 후 재발행할 때마다 `revision_no + 1` 불변 스냅샷 생성.
   - 초안 상태에서 사용자가 명시적으로 `[버전 스냅샷 저장]`을 누를 때 생성.
2. **문단 단위 JSON AST & 텍스트 Diff**:
   - 사용자가 수정 이력 드로어(`SCR-BLOG-013`)에서 과거 버전을 선택하면 현재 본문과 선택한 리비전 간의 추가된 문단(초록색 하이라이트)과 삭제된 문단(빨간색 취소선)을 시각적으로 비교한다.
3. **안전한 비파괴 복원 (Non-destructive Restore)**:
   - 과거 버전(예: `revision_no = 3`)으로 복원(`POST .../revisions/{id}/restore`)을 실행하더라도 `revision_no = 4, 5` 이력을 삭제하지 않고, `revision_no = 3`의 본문을 복사한 **새로운 최신 리비전(`revision_no = 6`, 요약: `'버전 #3에서 복원됨'`)**을 생성하여 언제든 다시 되돌릴 수 있도록 설계한다.
