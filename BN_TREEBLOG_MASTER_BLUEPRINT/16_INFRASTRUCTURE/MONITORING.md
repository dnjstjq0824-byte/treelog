# MONITORING.md — OpenTelemetry 기반 통합 관측성(Observability) 및 알람 정책

## 1. 핵심 SLI / SLO 및 경보(Alerting) 임계치
| 관측 지표 (SLI) | 목표치 (SLO) | Warning 알람 기준 | Critical (즉시 호출) 기준 |
| :--- | :--- | :--- | :--- |
| **서비스 가용성 (Uptime)** | `>= 99.95%` | 5xx 에러율 > `0.5%` (5분간) | 5xx 에러율 > `2.0%` (2분간) |
| **공개 블로그 SSR 응답 지연 (TTFB)** | P95 < `150ms` | P95 > `250ms` (10분간) | P95 > `500ms` (5분간) |
| **API 쓰기(발행/댓글) 응답 지연** | P95 < `200ms` | P95 > `400ms` | P95 > `1,000ms` |
| **예약 발행 실행 지연 (Schedule Lag)** | `< 5초` | `> 15초` | `> 60초` |
| **비공개/삭제 색인 제거 지연 (`critical` 큐)** | `< 1초` | 큐 대기 > `100건` | 큐 대기 > `500건` 또는 DLQ 발생 |
| **복식부기 원장 대사 불일치 (`Debit != Credit`)**| **`0건` (절대 불변)** | - | **단 1건이라도 발생 시 즉시 P1 경보** |
