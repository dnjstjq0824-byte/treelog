# COMMENTS_REACTIONS.md — 댓글·대댓글·비밀댓글·공감·북마크 상세 명세 (제8조)

## 1. 계층형 댓글·대댓글 및 비밀댓글 보안 규칙
1. **2단계 계층 구조 (`depth = 0` 원댓글, `depth = 1` 대댓글)**:
   - 가독성과 모바일 화면 폭(320px) 보존을 위해 시각적 들여쓰기는 최대 1단계(`depth = 1`)로 제한하되, 대댓글에 대한 답글 작성 시 `@대상닉네임` 멘션 태그를 자동 부착하여 대화 맥락을 명확히 유지한다.
2. **비밀 댓글 (`is_secret = true`) 서버 측 마스킹**:
   - 비밀 댓글의 본문(`content_text`)은 오직 **1) 댓글 작성자 본인, 2) 상위 원댓글 작성자(비밀 대댓글인 경우), 3) 해당 블로그의 `OWNER`/`ADMIN`/`EDITOR`**에게만 전송된다.
   - 그 외 사용자에게는 서버 API 직렬화 단계에서 `content_text: "비밀 댓글입니다."`, `author_display_name: "익명"`으로 마스킹하여 네트워크 패킷 검사를 통해서도 비밀 댓글 내용을 볼 수 없도록 보호한다.

## 2. 6종 공감 리액션 시스템
- 게시글 하단 공감 바는 기본 `LIKE`(좋아요 ❤️) 외에 `LOVE`(최고예요 👍), `HELPFUL`(유익해요 💡), `FUNNY`(재밌어요 😄), `TOUCHING`(감동이에요 🥺), `INSIGHTFUL`(깊이있어요 🧐) 6종 반응을 지원하여 풍부한 감정 피드백을 제공한다.
